# ミサイルの動作

## 発射と誘導

- ミサイルは`LaunchPoint`の青いZ軸方向へ発射されます。
- `FlyStraightTime`中は直進し、その後に設定した誘導方式が働きます。
- MCLOSは射手の上下左右入力で進行方向を変えます。
- SACLOSは`GuidanceReference`の照準線へ旋回します。
- 複数同時誘導では、MCLOS弾は同じ操作を、SACLOS弾は同じ照準線を使用します。

## 飛翔特性

- `Acceleration`で加速し、`MaxSpeed`で最高速度を制限します。
- `AirPhysicsStrength`は動力飛翔中の横滑りを抑えます。
- Flight Instabilityを有効にすると、動力飛翔中に滑らかな上下左右の揺らぎを加えます。
- `RollVisualRoot`を設定すると、物理挙動を変えずに見た目だけをロールできます。

## 誘導終了と弾道飛行

ワイヤー切断、手動操作、誘導喪失などで誘導が終了した後も、`MaxLifetime`までは動力飛翔を続けます。

`MaxLifetime`へ到達すると推進・誘導・指令ワイヤーを停止し、重力を受ける弾道飛行へ移ります。`BallisticLifetime`も終了すると、損傷や爆発を発生させず待機状態へ戻ります。弾道飛行中に通常着弾した場合は、設定した損傷と演出を適用します。

## ミサイルの再利用

発射ごとにミサイルを新規作成せず、`ProjectilePool`へ登録したミサイルを再利用します。すべて使用中の場合は、誘導が終了した古いミサイルを優先して回収し、それでも回収できない場合は最も古い誘導中のミサイルを回収します。回収されたミサイルは消滅し、その際に爆発は発生しません。

## 弾薬と再装填

`LaunchPoints`へ装填された弾を撃ち切り、総残弾が残っている場合は、`RackReloadTimeSeconds`経過後に次のラックを装填します。

## 発射制限

- `AllowFiringWhenGrounded`を無効にしたSacc航空機は、`Taxiing`中に発射できません。`SAVControl`が未設定ならこの制限は適用しません。
- `MaximumFiringSpeed`へ正の値を設定すると、車両Rigidbodyの合成速度がその値（m/s）以上の間は発射できません。0以下は無制限です。Rigidbodyが未設定なら速度制限は適用しません。
- 制限により拒否された入力では、弾薬、再装填、発射間隔、待機中ミサイル、エフェクトを変更しません。
