# 操作方法

操作キーは車両側のDialFunctionとKeyboard Controlsの登録設定に従います。

| 操作 | VR | デスクトップ |
| --- | --- | --- |
| 発射 | DialFunctionで武装を選び、トリガーを引いて発射します。 | 武装を選択し（初期設定では`1`キー）、`Space`キーで発射します。 |
| 誘導（MCLOS） | 飛翔中に右手コントローラーのジョイスティックを倒してミサイルの進行方向を修正します。 | 飛翔中に矢印キーを操作してミサイルの進行方向を修正します。 |
| 誘導（SACLOS） | 右手コントローラーをUse（グリップ等）した状態でコントローラーを傾け、照準器を目標へ向け続けます（FSE Turret Control使用時）。 | `W/A/S/D`キーで照準器を目標へ向け続けます（FSE Turret Control使用時）。 |

FSE Turret Controlを使用して照準する場合は、照準映像のズームが可能です。VRモードではDialFunctionでSight Zoomを選択した状態でトリガーを引きながら手を前後へ動かします。デスクトップモードでは`Q`、`E`キーで操作します。

## 誘導中の再入力

誘導中のミサイル数が`MaxConcurrentGuidedShots`の上限に達した状態で再度発射操作を行うと、最も古い誘導中ミサイルの誘導が終了します。この時点の入力では新規ミサイルは発射されず、次の独立した発射入力によって改めて発射条件が判定されます。

この動作は、`FSE_DFUNC_MissileLauncher`の`AllowDetachOnFireInput`が有効（既定）の場合です。無効の場合、上限に達した状態での発射操作では誘導が終了せず、入力は無視されます。命中、誘導時間の終了、離席、Take Controlによる役割の交代、Respawn、撃破などでは、無効の場合も従来どおり誘導が終了します。上限未満であれば、無効の場合も発射操作で次のミサイルを発射できます。ただし、空いているミサイルがなく、誘導中のミサイルしか残っていないときは発射されません。

誘導を終了したミサイルは慣性で飛翔を続けますが、再度誘導することはできません。
