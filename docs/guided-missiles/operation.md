# 操作方法

操作キーは車両側のDialFunctionとKeyboard Controlsの登録に従います。

| 操作 | VR | デスクトップ |
| --- | --- | --- |
| 発射 | DialFunctionで武装を選び、トリガーで発射します。 | 武装を選び（デフォルトでは`1`キー）、`Space`で発射します。 |
| 誘導（MCLOS） | 飛翔中に右手コントローラーのジョイスティックでミサイルの方向を修正します。 | 飛翔中に矢印キーでミサイルの方向を修正します。 |
| 誘導（SACLOS） | 右手コントローラーをUseした状態でコントローラーを傾けて照準器を目標へ向け続けます（FSE Turret Controlを使用する場合）。 | `W/A/S/D`で照準器を目標へ向け続けます（FSE Turret Controlを使用する場合）。 |

FSE Turret Controlを使用して照準する場合は、照準映像をズームすることができます。VRモードではDialFunctionでZoomを選択した状態でトリガーを押しながら手を前後へ動かします。デスクトップモードでは`Q`、`E`キーで操作します。

## 誘導中の再入力

誘導中ミサイル数が`MaxConcurrentGuidedShots`へ達した状態で再度発射入力すると、最も古い誘導中ミサイルの誘導を終了します。その入力では新しいミサイルを発射しません。次の独立した入力で発射条件を改めて判定します。

誘導を終了したミサイルは飛翔を続けますが、再び誘導することはできません。
