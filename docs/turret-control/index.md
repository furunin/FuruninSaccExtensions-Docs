# FSE Turret Control

FSE Turret Controlは、照準器や砲塔の左右・上下回転を操作し、その向きを同期するギミックです。

- 左右軸と上下軸を分けた主照準器
- 主照準へ追従する別砲塔
- Desktopの`W/A/S/D`操作
- VR右手Gripによる手動照準
- HMD方向へ追従するHEAD SLAVE
- 対応するSacc車両を照準方向へ追尾するTarget Tracking
- Sight Cameraの直接FOV操作、Zoom、距離計
- Sight CameraのFOVに応じた手動照準速度補正

Guided Missilesと組み合わせられますが、機関砲や独立した照準カメラにも使用できます。
