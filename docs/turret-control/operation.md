# 操作方法

## 手動照準

VRモード時は、右手グリップ（中指ボタン）を押した時点を中立位置として、右手コントローラーを傾けて照準を操作します。

| 照準操作方向 | VR | デスクトップ |
| --- | --- | --- |
| 上下 | 前後方向 | `W/S`キー |
| 左右 | 左右方向 | `A/D`キー |

## HEAD SLAVE

- `HeadSlaveVROnly`が有効な場合はVRだけ、無効な場合はDesktopとVRで使用できます。DialFunctionでHEAD SLAVEを選択すると、照準器が頭または視点の左右・上下方向へ追従します。
- VRでは、右手コントローラーのグリップ（中指）を押しながらコントローラーを傾けると、HMDの追従方向に対して照準方向を上下左右へ補正できます。

## Sight Camera／Zoom

照準映像の倍率を連続式と切替式の2つの方式で制御することができます。連続式では倍率の操作によって映像のFOVが滑らかに変化し、切替式ではあらかじめ設定された倍率に瞬時に切り替わります。

操作前にDialFunctionでSight Zoomを選択します。SH-1 SampleのCopilot Seatでは、`V`キーでSight Zoomを選択してから`Q/E`キーを操作します。

| 倍率制御方式 | VR | デスクトップ |
| --- | --- | --- |
| 連続式 | 左手コントローラーのトリガーを押しながらコントローラーを前後へ移動 | `Q/E`キー |
| 切替式 | 左手コントローラーのトリガーを押す | `Q/E`キー |
