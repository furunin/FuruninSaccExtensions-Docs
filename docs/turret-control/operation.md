# 操作方法

## 手動照準

VRモード時は、右手グリップ（中指ボタン）を押した時点をニュートラル位置とし、右手コントローラーを傾けて照準を操作します。

| 照準操作方向 | VR | デスクトップ |
| --- | --- | --- |
| 上下 | 前後方向 | `W/S`キー |
| 左右 | 左右方向 | `A/D`キー |

デスクトップモード時は、照準キーを押し続けると照準が徐々に加速します。左`Shift`キーを押しながら照準キーを押すと照準がゆっくり動き、細かく狙いを合わせられます。照準キーと減速キーは[コンポーネント](components.md)の設定で変更できます。

## HEAD SLAVE

- `HeadSlaveVROnly`が有効な場合はVR限定、無効な場合はデスクトップとVRの両方で使用できます。DialFunctionでHEAD SLAVEを選択すると、照準器が頭または視点の上下左右の動きに追従します。
- VRでは、右手コントローラーのグリップ（中指）を押しながら傾けると、HMDの追従方向に対して照準方向を上下左右へ微調整（トリム補正）できます。

## Sight Camera／Zoom

- 照準映像の倍率は「連続式」と「切替式」の2つの方式から選んで制御できます。連続式では操作に応じて映像のFOVが滑らかに変化し、切替式ではあらかじめ設定された倍率へ瞬時に切り替わります。
- 通常は操作前にDialFunctionでSight Zoomを選択します。SH-1 SampleのCopilot Seatでは、`B`キーでSight Zoomを選択してから`Q/E`キーを操作します。
- `AllowZoomWhileDeselected`を有効にすると、別のDialFunctionを選択している最中でもデスクトップやVRからズーム操作を行えます。VRでは、選択中のDialFunctionが同じトリガー入力を使用していると操作が重複するため注意してください。

| 倍率制御方式 | VR | デスクトップ |
| --- | --- | --- |
| 連続式 | Sight Zoomを選択した側のコントローラーのトリガーを引きながら、車両の前後方向へ手を動かす | `Q/E`キー |
| 切替式 | Sight Zoomを選択した側のコントローラーのトリガーを引く | `Q/E`キー |
