# Furunin Sacc Extensions

Furunin Sacc Extensionsは、VRChat向け乗り物アセット「SaccFlightAndVehicles」へ機能を追加する拡張ギミックです。

## ギミック一覧

### FSE Guided Missiles

乗り物へ誘導ミサイルを搭載するための機能です。複数の誘導方式のミサイルを選択できます。

[FSE Guided Missilesを導入する](guided-missiles/installation.md)

### FSE Turret Control

照準器や砲塔の操作、別砲塔の追従、デスクトップ／VR操作対応、照準のHMDへの追従、照準カメラ制御をまとめて扱う砲塔制御機能です。Guided Missiles以外の機関砲や照準器にも使用できます。

[FSE Turret Controlを導入する](turret-control/installation.md)

## 文書について

各ガイドは、必須セットアップと任意機能を分けて説明しています。Inspectorに表示されるComponent名とField名は英字表記のまま記載します。
