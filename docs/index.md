# Furunin Sacc Extensions

Furunin Sacc Extensionsは、VRChat向け乗り物アセット「SaccFlightAndVehicles（以下Sacc）」へ機能を追加する拡張ギミックです。

## ギミック一覧

### [FSE Guided Missiles](guided-missiles/index.md)

乗り物へ誘導ミサイルを搭載するための機能です。複数の誘導方式のミサイルを選択できます。

### [FSE Turret Control](turret-control/index.md)

照準器や砲塔の操作、別砲塔の追従、照準のHMDや視線への追従、照準カメラ制御をまとめて扱うタレット制御機能です。Guided Missilesと組み合わせて使用できるほか、単独でも使用できます。

## 対応環境

- Unity 2022.3.22f1
- VRChat Worlds SDK 3.10.4
- SaccFlightAndVehicles 1.8.1

## パッケージ導入方法

1. ワールドプロジェクトにSaccFlightAndVehiclesを導入します。
2. Furunin Sacc Extensionsのunitypackageをインポートします。
